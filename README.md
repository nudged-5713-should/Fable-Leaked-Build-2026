Fable is a fantasy action RPG set in the legendary land of Albion, developed by Playground Games and published by Xbox Game Studios. Explore a strange fairy-tale world, face dangerous creatures, and carve out your own idea of heroism. This repository contains an unofficial leaked pre-release build: raw, unfinished, and surfaced ahead of the intended release.

For players who want a story-focused fantasy action RPG and do not mind rough edges, unfinished content, and the unstable atmosphere of an early build.

 **Q: Will this affect my official game install or saves?**
